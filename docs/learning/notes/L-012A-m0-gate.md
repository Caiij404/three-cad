## 3. 最小实验

```powershell
. ./scripts/use-node.ps1
npm.cmd run check:worker
npm.cmd run build
npm.cmd run check:gate
```

输入是两内核同页并行的固定夹具、非法 solid 输入、30 次热身后的各内核往返采样，以及真实静默 Worker 的默认 10 秒截止。期望指定数值成立、错误明确且后续真实求解恢复。

环境和源码版本：[TECH-SPIKE](../../TECH-SPIKE.md)。体积/长度容差继承各夹具；计时来自实际 performance.now，不能与完整 10 万面模型性能混写。
