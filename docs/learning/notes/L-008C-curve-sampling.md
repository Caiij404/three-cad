## 1. 本次问题

领域保存圆心、半径和端点，三角网格却需要有限个顶点。怎样选择段数，同时满足 0.05 mm 弦误差和 5° 步进上限？本次只生成边界点，不判断它们能否组成有效区域。

## 2. 原理与数据流

一段圆弧的弦中点距离圆周最远，误差为 `e = 2r·sin²(θ/4)`。反解得到 `θ = 4·asin(sqrt(e/(2r)))`，再与 5° 取较小值，使用 `ceil(总扫角/θ)` 段。这个表达式避免在微小误差下直接计算 `acos(1-e/r)` 的相消。

圆至少 24 段；需要超过 4096 段时明确拒绝，不能截成 4096 后声称精度达标。默认 5° 已使普通圆至少 72 段，24 是放宽自定义精度时仍保留的下限。

输入是求解后的 double 领域实体、精度选项；输出是 double 点列、实际段数、扫角与误差界。圆末点复制首点，圆弧保留原有领域端点与方向。原生容差内的两端半径差会消耗误差预算；预算不足时拒绝，不偷偷移动端点。

```mermaid
flowchart LR
    Domain[真实求解后的领域圆或弧] --> Budget[半径差与弦误差预算]
    Budget --> Count[误差角和最大角共同决定段数]
    Count --> Guard[容量与解析极值范围检查]
    Guard --> Output[double 点列与误差界]
    Output --> Later[后续轮廓连通和分类]
```

代码见 [sampleSketchEntity](../../../src/core/geometry/sample-entity.ts)，独立测量见 [测试](../../../tests/curve-sampling.test.mjs)。测量从输出点计算弦中点半径差、相邻半径的 atan2 夹角，不以实现报告的误差界充当实际结果。

| 检查 | 期望 | 实际 | 证据 |
| --- | --- | --- | --- |

| R10000 | 弦误差更严格 | 994段；0.04994552924mm，步进0.006321112rad | 同上 |

| 原弧端点差5e-6mm | 保留端点并留预算 | 默认通过；1e-6mm目标拒绝 | 同上 endpoint-budget |

6/6测试通过。补查发现只检查采样顶点可能漏掉曲线极值，因此加入解析极值；R10000、圆心y=0.01mm的圆即使采样未落在最高点也会拒绝。16领域测试与14个纯核心文件边界检查通过，见 [领域重放](../evidence/T-202A-domain-replay.json) 与 [事务重放](../evidence/T-202A-transaction-replay.json)。类型检查/构建通过，既有约750kB主包提示保留。
