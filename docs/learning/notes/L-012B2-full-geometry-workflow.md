## 1. 本次问题

实际画出来的A/B经过布尔、改尺寸、保存打开与级联历史，是否仍与解析几何预测一致？此前真实预构造夹具已经验证文件管线，本次从界面空项目绘制开始接上全部步骤。

## 2. 原理与数据流

输入是固定尺寸/基点的两个草图，输出是稳定ID对应的实际网格指标。改A只应改变依赖它的几何；文件打开后缓存和历史重新建立，稳定ID仍能驱动传播。级联一次移除来源及后代，历史应精确恢复文档与全部指标。

```mermaid
flowchart LR
    UI[画固定A/B] --> Bool[四布尔 / 解析体积包围盒]
    Bool --> Edit[A宽20到25 / 自动传播]
    Edit --> File[下载 / 重开 / 再编辑]
    File --> History[级联五后代 / 精确历史]
```

A初始x=[0,20]，B=[10,30]，共同高20、深20。并集长30体积12000，差集长10体积4000，交集长10体积4000。A宽25时交集长15为6000，B-A只剩x=[25,30]体积2000，同时检查操作数顺序和参数传播。

## 3. 最小实验

六次空项目原生UI画固定A/B，DOF0；创建union、A-B、B-A、intersect。核对初始体积、差集x范围；宽25后核对全部体积和ID。实际下载JSON、刷新、打开，文档/全部网格指标精确相同。重开后宽26交集6400；撤销回精确文件快照。A级联列五后代，剩B草图/实体，undo/redo精确比较。
